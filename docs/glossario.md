# 📖 Glossário de Termos e Jargões

Consulte antes de interpretar exportações e relatos. Adicione termos novos em ordem alfabética, com a definição usada **na Ten Internet**.

| Termo | Significado no contexto da Ten |
| :--- | :--- |
| **Balanço da fila** | Saídas ÷ entradas de demandas do setor no período. Substitui "resolutividade" (ver `regras_metricas.md`). |
| **CGNAT** | NAT de grande escala usado para compartilhar IPs públicos entre clientes. |
| **CT** | Container (Proxmox/LXC) incluído na rotina de backup. |
| **CTO** | Caixa de Terminação Óptica na rede de campo. |
| **FCR / Resolutividade** | Resolução no primeiro contato — métrica do Service Desk, **não** do TI. |
| **Fullcam** | Plataforma de câmeras em nuvem comercializada pela Ten; automações de inadimplência e instalação no AutoTickets. |
| **HT** | Horas trabalhadas apontadas em um protocolo do Voalle. |
| **N2-TI** | Atendimento de segundo nível realizado pelo TI. |
| **NOC** | Centro de operações de rede (inclui o parceiro Made4NOC). |
| **ONT** | Equipamento óptico na casa do cliente (Datacom, Parks). |
| **Pontomais** | Sistema de ponto eletrônico; referência para a jornada real. |
| **RB** | RouterBoard MikroTik. |
| **Sol. Interna / Sol. Externa / Tarefa avulsa** | Tipos de protocolo do Voalle — ver `classificacao_protocolos.md`. |
| **TMA / TMR** | Tempo médio de atendimento / tempo médio de resolução. |
| **Voalle** | ERP principal da empresa. |
| **WiFeed** | Captive Portal da rede "TEN_Wi-Fi"; clientes autenticam por CPF (voucher), não clientes por celular. |
| **ZEUS / Native PBX** | Telefonia fixa corporativa. |
