# 🗂️ Classificação de Protocolos no Voalle

Regra de abertura de protocolos do Setor de TI. Use-a para classificar demandas no relatório e para apontar abertura incorreta.

## 1. Demandas administrativas → **Tarefa avulsa**

- Impressora
- Computador
- Ramal
- Problemas entre o colaborador e o sistema

## 2. Demandas complexas → **Solicitação interna**

Várias etapas, processos, dependência de terceiros ou atuação de mais de um colaborador:

- Problemas nos sistemas (abrir suporte Native, Voalle, Fullcam...)
- Estudos internos, homologações e testes
- Situações que possam passar para outros colaboradores (do mesmo setor ou de outros)
- Solicitações de material (estoque)
- Reembolsos

Quando mais de um colaborador atuar no mesmo problema: dentro da solicitação interna, **Tarefas / Processos ▸ Adicionar nova tarefa ▸ Tarefa Comum** (ou **Aprovação**), uma para cada colaborador.

## 3. Demandas que envolvem diretamente um cliente → **Solicitação externa** (obrigatório)

- Suporte a técnico de campo
- Viabilidade técnica
- Visita técnica feita pelo próprio TI — se mais de um colaborador participar, abrir uma tarefa dentro da mesma solicitação para cada um registrar sua atividade.
